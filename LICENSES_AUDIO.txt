Violet Lanterns
v1.9.7 Audio Licenses and Source Notes

This build uses uploaded real audio packs and stores selected runtime copies locally as MP3.

Included source packs uploaded by Sarel:
1. kenney_ui-audio.zip
   Source: Kenney UI Audio
   License: Creative Commons CC0
   Runtime use: buttons, menu clicks, toggles.

2. kenney_interface-sounds.zip
   Source: Kenney Interface Sounds
   License: Creative Commons CC0
   Runtime use: choices, confirmations, save/load, route lock, CG unlock, achievement, ending, error, page/panel sounds.

3. Rain OGG.zip
   Source: OpenGameArt - Rain (loopable)
   Author listed on source page: Ylmir
   License listed on source page: CC0
   Runtime use: rain and heavier rain/storm ambience.

4. Free Wind Chimes Ogg.zip
   Source: OpenGameArt - Wind Chimes
   Author listed on source page: pmiller
   License listed on source page: CC0
   Runtime use: garden, festival/chime ambience, menu loop.

Implementation:
- Selected OGG source files were copied into assets/audio/local/vendor/originals/.
- Runtime MP3 copies were created under assets/audio/local/vendor_runtime_mp3/.
- MP3 runtime copies are used because they are generally more reliable on iPhone/Safari-style browsers than OGG.
- Generated Python sounds are no longer the preferred runtime path; they remain only as emergency fallback.

Known limitation:
- No real café or train-platform ambience file was uploaded, so v1.9.7 intentionally leaves café/train ambience silent rather than using fake generated room tone.
